# Not Defteri Uygulaması

Modern, şık, Türkçe/İngilizce dil destekli, etiketleme ve yerel depolama özelliklerine sahip React + TypeScript not alma uygulaması.

## Özellikler

- 📝 **Hızlı Not Oluşturma ve Düzenleme**: Not başlıkları, içerikleri ve etiketler ekleyebilirsiniz.
- 🌙 **Koyu ve Aydınlık Tema**: Tek tıklamayla yumuşak geçişli tema değişimi.
- 🔍 **Anlık Arama ve Filtreleme**: Notlarınızı başlık, içerik veya etiketlere göre anında arayın.
- 🌐 **Çoklu Dil Desteği**: Türkçe ve İngilizce arayüz desteği.
- 💾 **Veri Yedekleme**: Notlarınızı JSON formatında dışa aktarın veya içeri aktarın.
- 📱 **Tam Mobil Uyum**: Masaüstü, tablet ve mobil cihazlarda sorunsuz kullanım.

## Kurulum ve Çalıştırma

Projeyi bilgisayarınızda çalıştırmak için aşağıdaki adımları izleyin:

```bash
# Bağımlılıkları yükleyin
npm install

# Geliştirici sunucusunu başlatın
npm run dev

# Production sürümünü derleyin
npm run build
```

## Teknolojiler

- **React 18**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Lucide React Icons**
